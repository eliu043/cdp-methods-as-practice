# Lots in Commons — website source

This GitHub repository is the authoritative source for the website.

## Main routes

- `index.html` — vertical Presentation
- `field.html` — draggable research Field
- `archive.html` — expandable working Index
- `ani-liu.html` — archived Ani Liu precedent analysis

## Supporting files

- `presentation.css` and `presentation.js` — Presentation styling, order, and navigation
- `field.css` and `field.js` — Field styling, resources, dragging, panning, and zooming
- `style.css` and `script.js` — working Index styling and expand/collapse behavior
- `ani-liu.css` and `ani-liu.js` — precedent-analysis styling and interactions
- `images/` — locally archived project and precedent imagery
- `session-notes-019fbeba.md` — research and editorial notes extracted from the poster/presentation session
